# CodSoft Java Development Internship

## 📌 Internship Overview

This repository contains the Java development tasks completed as part of the **CodSoft Java Development Internship**.

The projects demonstrate fundamental Java programming concepts including user input, conditional statements, loops, arrays, object-oriented programming, data validation, and menu-driven applications.

## 🛠️ Technologies Used

* Java
* Java SE
* Object-Oriented Programming
* VS Code
* Git
* GitHub

## 📂 Completed Tasks

### Task 1 — Number Game

A console-based number guessing game where the program generates a random number and the user attempts to guess it.

**Features:**

* Random number generation
* User guesses
* High/low feedback
* Attempt limit
* Multiple rounds
* Score calculation

**File:**
`task1_NumberGame/NumberGame.java`

---

### Task 2 — Student Grade Calculator

A console-based application that calculates a student's total marks, average percentage, and grade.

**Features:**

* Student information input
* Multiple subject marks
* Marks validation
* Total marks calculation
* Average percentage calculation
* Grade calculation

**File:**
`task2_StudentGradeCalculator/StudentGradeCalculator.java`

---

### Task 3 — ATM Interface

A menu-driven ATM application developed using Java classes and object-oriented programming concepts.

**Features:**

* Check account balance
* Deposit money
* Withdraw money
* Balance validation
* Transaction messages
* ATM and BankAccount classes

**Files:**

* `task3_ATMInterface/ATM.java`
* `task3_ATMInterface/BankAccount.java`
* `task3_ATMInterface/Main.java`

---

### Task 4 — Quiz Application with Timer

A console-based multiple-choice quiz application with timed questions and score calculation.

**Features:**

* Multiple-choice questions
* Four answer options
* Question timer
* Answer validation
* Correct and incorrect answer tracking
* Final score
* Percentage calculation

**File:**
`task4_QuizApplication/QuizApplication.java`

---

### Task 5 — Student Course Registration System

A console-based course registration system that allows students to view courses, register for courses, and drop registered courses.

**Features:**

* Student information
* Course information
* Course codes
* Course descriptions
* Course schedules
* Course capacity
* Available slots
* Course registration
* Course removal
* Registered course display

**File:**
`task5_CourseRegistration/CourseRegistration.java`

## ▶️ How to Run

Open a terminal inside the required task folder.

Compile the Java file:

```bash
javac FileName.java
```

Run the program:

```bash
java ClassName
```

For Task 3, compile all Java files together:

```bash
javac *.java
```

Then run:

```bash
java Main
```
